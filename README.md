# 🐸 Count With Freddy the Frog — A 10-Minute Sing-Along

**A viral, educational nursery rhyme that teaches counting 1–10 and simple addition.**

Meet **Freddy the Frog**, who hops across ten lily pads collecting friends along the
way. Every hop adds one more, so children *count up* and *add up* at the same time.
The song is built as a medley of short, repeatable segments that total about **10
minutes** — perfect for a full-length kids' video, a classroom sing-along, or a
looping playlist.

---

## Why it's built to go viral

- **One sticky hook** ("*Hop, hop, add-em-up, how many friends have we?*") that
  repeats after every segment so kids can shout the answer.
- **A dance move per number** — a physical action for 1 through 10 that begs to be
  copied and duet-ed.
- **Call-and-response** counting so children participate instead of just watching.
- **Predictable pattern, tiny surprises** — each verse is the same shape with a new
  friend, which is exactly what makes a rhyme "stick."
- **A big finale** (the "Add It All Up" rap) that rewards kids for staying to the end.

## How to use it

- **Watching:** Play start to finish. Kids echo every number and shout the answer to
  the hook.
- **Classroom:** Pause after each hook and let the room call the total.
- **At home:** Use fingers! Every number 1–10 has a matching number of fingers held up.

Sing it, hop it, add it up. 🐸➕

# Brainy Baby — Channel Launch Kit

Everything you need to take the channel live. Asset URLs + job IDs live in `brand-assets.md`.

## 1. Set up the channel (YouTube Studio → Customize channel → Branding)
- [ ] **Profile picture:** upload the **logo** (1024×1024). Recommended 800×800, min 98×98. ✅ meets spec.
- [ ] **Banner:** upload the **4K banner** (4096×2294). Above YouTube's 2048×1152 min & 2560×1440 rec. ✅
      - Keep in mind: only the central *safe area* (1235×338) shows on all devices — our title + owl are already centered there.
- [ ] **Video watermark:** upload the **transparent logo** cutout (branding → video watermark), set to show at end of videos.

## 2. Channel details (Customize channel → Basic info)
- **Name:** Brainy Baby
- **Handle:** @BrainyBaby (or nearest available, e.g. @BrainyBabyRhymes)
- **Tagline / description starter:**
  > Brainy Baby is a cozy world of nursery rhymes, counting songs, and sing-along
  > learning for little ones. Gentle pastel animation, classic rhymes, and a friendly
  > brainy owl to help babies and toddlers learn through music. New songs every week!
- **Keywords:** nursery rhymes, kids songs, baby songs, toddler learning, ABC song,
  counting songs, lullaby, sing along, preschool, educational kids videos.

## 3. First uploads (thumbnails ready in this kit)
Launch with a small batch so the channel doesn't look empty:

## 4. Compliance (important for kids content)
- [ ] Mark videos **"Made for Kids"** (YouTube requires this; COPPA). Set at upload or channel-level.
- [ ] Note: "Made for Kids" disables some features (comments, end screens, personalized ads).
- [ ] Keep audio/music properly licensed. Sung tracks are produced externally via Suno
      (see `suno-prompt.md`); confirm your Suno license covers commercial/monetized use.

## 5. Nice-to-have before/after launch

- [ ] Consistent upload schedule (e.g. weekly) — helps the algorithm.
- [ ] Playlists: "Nursery Rhymes", "Counting Songs", "Lullabies".
